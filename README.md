# DesktopOrganizer

面向 Windows 10/11 的 .NET 10 WPF 私人桌面整理软件。程序在桌面层绘制替代图标和分类框，并临时隐藏 Explorer 原生桌面图标。

## 核心功能

- 扫描当前用户桌面和公共桌面的真实项目；回收站作为独立系统小组件显示，不混入普通图标和分类。
- 自由拖动、网格吸附、挤压排列和一键对齐。
- 新建、移动、缩放、重命名、收起和删除虚拟分类框；布局锁定时悬停收起分类可临时预览内容，底部空间不足时向上展开，不改变收起状态或布局占位。
- 本地自动分类、分类预览、新项目归类和取消分类。
- “工作、学习、临时项目”等命名工作区：列表双击非当前工作区，或用方向键选中后按 Enter，即可进入既有差异确认与切换流程；按 F2 可重命名，按 Ctrl+D 可从所选快照创建独立副本。预览、复制、切换和恢复只改变本地视觉布局配置，同时保存分组、自由图标、控制面板、回收站组件、只读文件夹入口与显示器拓扑。
- 新出现的桌面项目进入待整理收件箱，可直接编辑本地标签并按 Ctrl+S 保存、逐项接受可靠建议，或在列表中按 Ctrl+Shift+Enter 一键接受全部可靠建议；也可用 Enter 组合键连续接受、留在桌面或稍后处理，批量操作会保留低可靠度、稍后处理和手工保护项目。
- 桌面自由图标、分组图标和收起分组预览共用本地标签摘要与编辑入口，多选项目可一次添加或移除标签；快速搜索支持名称、类型、分组、标签、近期新增和智能视图，结果列表中可按 Ctrl+F 返回并全选查询文本；只查询已经加载的桌面项目，不扫描其它目录，也不读取文件正文。
- 自定义规则采用“草稿（默认禁用）→预览→执行一次→启用自动应用”生命周期；编辑新规则或未保存修改时可在编辑区按 Ctrl+S 保存为禁用草稿，逐项显示命中原因、目标与冲突，也可一键停用全部自动应用并保留已有结果；动作仅限虚拟分组、标签和收件箱。
- 标签、未分类/近期新增/待确认/最近移动智能视图和透明 JSON 导入导出均保存在本地，不改文件名，也不创建 sidecar。
- 在分类框之间拖动，也可拖入真实文件夹并移动真实文件；真实移动、回收站删除与撤销通过后台 STA 串行队列执行。
- 真实文件操作在进入后台队列前写入独立账本，逐项记录结果；操作中心可选中记录后按 Ctrl+C 或点击“复制所选详情”复制带表头的完整可见详情，并在自动刷新时保持同一记录；最近 20 次成功移动可跨会话恢复撤销候选，执行撤销时重新核验路径与稳定身份。
- 文件夹入口（Portal）以永久“真实文件夹 · 只读”标识显示指定目录，支持面包屑浏览、方向键选择后按 Enter 打开或进入、按 Ctrl+C 复制所选条目真实路径，以及资源管理器定位；当前目录变化会防抖自动刷新，不接受拖放，也不提供删除、移动或重命名真实内容的入口。
- 分类框标题菜单可一次选择或取消选择整组项目（包括尚未滚入视口的项目），多选项目可一次移入目标虚拟分组，也支持排序、批量移出、删除到回收站、资源管理器定位和双击打开；回收站组件支持状态显示、打开与清空。
- 智能布局、临时工作区、编辑模式、仅当前会话生效的安全模式和运行诊断。
- 覆盖完整虚拟桌面，支持左右/上下排列、负坐标显示器、独立任务栏工作区和不同 DPI 缩放。
- FileSystemWatcher 防抖刷新、后台扫描、按差异增量更新视觉树、分类框可视区域虚拟化、Shell 图标后台优先队列、布局原子保存和崩溃恢复。
- 文件重命名后保留图标坐标、所属分组与自动分类状态；关闭程序期间改名也可在下次启动时通过文件 ID 恢复。
- 原生托盘图标、单实例运行、安静开机启动和 Explorer 重启恢复。

运行时项目不依赖第三方 NuGet 包；自动化测试项目仅使用 Microsoft 测试工具和 Coverlet。

布局文件当前为 Version 18。Version 16 引入命名工作区，Version 17 引入收件箱、标签和用户规则，Version 18 引入只读文件夹入口；旧版 `layout.json` 会自动升级。工作区恢复不包含真实文件任务；显示器拓扑只保存设备名、工作区、DPI 和相对坐标；`ItemIdentities` 只保存真实桌面项目的路径与稳定身份；Portal 内容列表不写入布局。安全模式仍只在当前会话生效。

## 开发环境

- Windows 10 或 Windows 11
- .NET 10 SDK
- Visual Studio、JetBrains Rider 或 dotnet CLI

## 运行源码

双击 `run-source.cmd`，或执行：

```powershell
dotnet run --project DesktopOrganizer.csproj
```

## 发布单文件 EXE

双击 `publish-win-x64.cmd`。成功后输出到：

```text
release\win-x64\DesktopOrganizer.exe
```

`build-and-start.cmd` 会先发布，再启动生成的 EXE。


## 自动化验证

本地执行与 GitHub Actions 相同的编译、测试和发布流程：

```powershell
.\scripts\ci.ps1
```

也可以双击：

- `run-tests.cmd`：只执行还原、Release 编译和测试。
- `ci-local.cmd`：执行还原、警告即错误编译、测试、覆盖率采集和 win-x64 单文件发布。

输出位置：

```text
artifacts\test-results
artifacts\publish\win-x64
artifacts\DesktopOrganizer-win-x64.zip
```

## 常用操作

- 双击图标：打开文件、文件夹或回收站。
- 拖动自由图标：移动位置；开启网格吸附时自动对齐。
- 拖到另一图标位置：在启用挤压排列时预览后续图标移动。
- 拖入虚拟分类框：只修改布局，不移动真实文件。
- 拖入真实文件夹图标：确认后将移动任务排入后台队列；处理中图标会半透明并暂时禁用重复操作。
- “工作区”：创建、复制、预览、覆盖、重命名、删除或切换纯视觉工作区；复制所选快照不会切换当前布局，真实文件不会移动。
- “待整理”：审阅新项目建议；“快速搜索”只搜索当前已加载桌面项目，可用上下方向键选择，按 Enter 定位并返回桌面、Ctrl+Enter 打开、Shift+Enter 在资源管理器中显示。
- “自定义规则”：先预览逐项原因和冲突，再执行一次；只有成功执行过的规则才可由用户显式启用自动应用。
- “文件夹入口”：创建默认只读的真实文件夹 Portal；目录重解析点只交给资源管理器打开，不在 Portal 内继续导航。
- “操作中心”：只读查看逐项账本状态、恢复核验和撤销能力；失败、中断或不确定操作不会自动重试。
- Ctrl+单击：多选；在分组中先 Ctrl+单击设置起点，再 Shift+单击可按当前显示顺序连续选择；Ctrl+A：选择全部已加载桌面项目；Esc：清除选择；Ctrl+Z：撤销最近一次可用的真实文件移动。快捷键只在桌面语境中执行，不会占用其他应用的按键。
- “安全模式”：本次运行内暂停实时监听、新项目自动归类和挤压预览；退出后恢复原偏好。
- “暂停整理”：恢复 Windows 原生桌面图标。
- “隐藏面板”：只隐藏控制栏，整理层继续运行。
- 托盘菜单：显示/隐藏、暂停/继续、刷新、开机启动和退出。

## 数据位置

布局文件：

```text
%AppData%\DesktopOrganizer\layout.json
```

独立文件操作账本：

```text
%AppData%\DesktopOrganizer\operation-journal.json
```

工作区、收件箱、规则、标签和 Portal 配置均在 `layout.json` 中；Portal 内容列表不持久化。账本与布局分开保存，损坏或无法写入时会进入保护态并阻止新的真实文件操作，不会用空账本覆盖原记录。

诊断日志：

```text
%AppData%\DesktopOrganizer\Logs
```

布局损坏时会备份为 `layout.corrupt-日期时间.json`。异常退出时，程序会使用恢复标记尝试重新显示 Explorer 原生桌面图标。

## 安全说明

工作区切换与恢复、虚拟分类、收件箱处理、规则、标签、搜索和 Portal 浏览都不会修改真实文件。只有以下显式操作会改变文件系统：

- 拖入真实文件夹；
- 删除到回收站；
- 撤销真实文件移动；
- 确认后清空回收站（不可撤销）。

真实操作的 `Queued` 和 `Running` 状态都必须先落盘。启动时只通过源路径、目标路径和稳定身份做只读核验，将遗留操作收束为成功、中断或状态不确定；程序不会自动再次执行。

若系统桌面图标没有恢复，可重新启动程序，或在桌面右键“查看”中勾选“显示桌面图标”，必要时重新启动 Windows 资源管理器。

## 当前限制

- 分类框已按可视行虚拟化，但自由桌面图标仍全部常驻视觉树；若桌面本身存在上千个未分组项目，仍会产生较多 WPF 控件。
- 单个 WPF 桌面宿主使用统一的客户区 DPI；不同缩放显示器的物理边界与工作区能够正确映射，但图标视觉大小在所有屏幕上保持一致。
- 程序仍会枚举 Shell 桌面根以定位回收站，但此电脑、网络、Linux 和第三方命名空间扩展都会在进入布局前被过滤；回收站图标提取异常时显示占位图标，不阻塞 UI。
- 全局输入监听需在 Windows 实机验证不同输入法、辅助工具和安全软件兼容性；监听只判断 Ctrl+A/Ctrl+Z/Esc 与鼠标按下目标，不记录文本，也不吞掉无关按键。
- 搜索不建立全盘或正文索引；没有任意目录监控、OCR 或云端 AI 分类。
- Portal 只枚举当前目录直属项目，单次最多显示 500 项；非递归 watcher 只刷新正在查看的当前目录，不监控子目录内部变化，不自动重试读取失败，也没有任何写操作菜单。
- 已经进入 Windows 原生文件 API 的单次移动或回收站操作不能安全强制终止；退出程序会取消尚未开始的后台项，但它们的 `Queued` 账本仍会保留并在下次启动标为中断。活动操作可能由系统继续完成，随后只读核验；跨磁盘拖入仍要求使用资源管理器。
