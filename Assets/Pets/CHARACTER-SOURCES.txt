黑发伙伴 / 粉发伙伴 / 夕阳双人

依据用户提供的双人物参考图，使用 OpenAI 内置官方图像生成工具设计动作，
随后在本地完成抠底、裁切、脚底对齐、眨眼局部贴合与动作节奏调整。
工具未暴露底层模型选择，未标称使用 Image 2.5。
参考图中的下半身未展示，长裤及鞋子为设计补全。
原图及设计工作文件由项目维护者另行保留在被 Git 忽略的 artifacts 目录。

黑发伙伴的 wave-v3.png 使用内置官方生图绘制连续抬臂、摆腕、收手姿势，
只将手臂局部接回原角色，保留头部、身体、腿部及脚底像素；不再旋转整人模拟挥手。
生成原图、提示词、对齐与拼接工具保留于 artifacts/black-wave-v3。

当前挥手使用 wave-v4.png。经用户明确同意，保留 v3 原画与角色纹理，
通过离线分段变形补充膝、髋、肩和头部的跟随与迟滞，并增加抬肘中间姿势。
脚底保留原像素，首尾使用原待机，21 帧共 1960 毫秒；无需运行时变形。
导出工具、参数和实际控件透明预览保留于 artifacts/black-wave-v4。
本轮两次整身生成稿因外观漂移与边缘杂色未采用，仅在该工作目录留档。

粉发伙伴的新版挥手使用内置官方生图重画连续手臂关键姿势，保留原有其他动作。
运动参考为 Ludo Wave 预览和 Nick Kinteris 的 Hand Waving 动作分析：
https://ludo.ai/tools/animation-presets/social
https://nickkinteris.com/2023/10/25/hand-waving/
参考视频及第三方画面未打包进程序。透明夕阳城楼由官方内置生图绘制，
本地去除不透明底色并对齐场景；仅为插画，不是建筑测绘还原。
挥手原稿另存 artifacts/pink-wave-reference-v2，场景及导出输入另存
artifacts/tiananmen-desktop-cutout-v1，均需单独保留。

夕阳双人使用已确认的双人全身夕阳稿，保留牵手关系与原画光色。
官方内置生图补全遮挡背景并生成闭眼表情，本地拆出人物、眼部与背景，
制作固定脚底的轻微呼吸、交替眨眼、点头回应和闭眼休息动画。
双人作为一个组合移动，不使用单人提起、摔倒动作。
分层源文件、掩码、逐帧 PNG 和处理提示词另存 artifacts/sunset-duo-animation。
后续肢体动作由官方内置生图绘制关键姿势，再将挥手、相视、牵手轻摆和依偎
局部接回原稿，保持原有腿部及脚底像素不变；待机时轮流播放互动。
补充关键稿、逐帧素材及提示词另存 artifacts/sunset-duo-actions-v2。
